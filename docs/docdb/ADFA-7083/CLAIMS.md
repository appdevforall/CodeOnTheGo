# Claims in the ADFA-7083 pages and how each was checked

`run` = executed by `test_examples.py` against a host build of the package (66 of 66 on plain 1.4.2, the package from the move to 1.4.2, 2026-11-13: 28 SQL examples, 19 of them run a second time, and 19 links; on 1.4.1 the `js_version` example and the kept result set example fail, as they should. Before that, 64 of 64 on 1.4.1 with the package's two patches, stack and garbage collection, which change none of the pages' claims, and on 1.4.1 without them, 2026-11-12: 27 SQL examples, 18 of them run a second time in the same session, and 19 links; earlier, 1.3.7-p20261112, upstream main at c8ae85a, and 1.3.7-1 to 1.3.7-5, 1.3.7 with patches 0001 to 0008). `code` = read in the source: the patched 1.3.7 up to 1.3.7-5, then upstream main at c8ae85a, then 1.4.1, whose `src/` and `libs/` differ from c8ae85a only in `SQLITE_JS_VERSION`, with the package's patches 0001 and 0002 (sqliteai/sqlite-js #22 and #23). `probe` = run by hand against the host build, in the accuracy review (2026-11-11), the review of PR 2241 (2026-11-12) or the move to 1.4.1 (2026-11-12). `TODO` = still open.
